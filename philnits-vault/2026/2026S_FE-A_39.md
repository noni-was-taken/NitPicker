# 2026S_FE-A_39
Which of the following is a software development model for a small, and cross-
functional team to develop a new social shopping platform, including creating user profiles,
following friends, sharing products, and personalizing recommendation? Here, this platform
constantly evolves, so frequent user feedback on all modules is expected.

a) Agile model
b) Prototyping model
c) Spiral model
d) Waterfall model
?
a) Agile model
