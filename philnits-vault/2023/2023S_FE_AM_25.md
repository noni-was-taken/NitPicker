# 2023S_FE_AM_25
Which of the following is an appropriate explanation of a relational database?

a) It connects a parent record and a child record by using a pointer.
b) It represents data in the form of a two-dimensional table.
c) It represents the structure and meaning of data by using tags.
d) It retains data and procedures in an integrated (or encapsulated) form.
?
b) It represents data in the form of a two-dimensional table.
