# 2021S_FE_AM_7
When a sequence of data, A, B, C, D, arrives in this order, which of the following is a
possible sequence that can be produced using a single stack?

a) A, D, B, C
b) B, D, A, C
c) C, B, D, A
d) D, C, A, B
?
c) C, B, D, A
