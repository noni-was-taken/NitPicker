# 2018A_FE_AM_30
In a DBMS, when multiple transaction programs update the same database
simultaneously, which of the following is a technology that is used to prevent logical
contradictions?

a) Exclusive control
b) Integrity constraint
c) Normalization
d) Reorganization
?
a) Exclusive control
