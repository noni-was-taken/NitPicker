# 2018S_FE_AM_7
Function F(n) is a recursively defined integer function that calculates the factorial of n for
any non-negative integer n. Which of the following is an appropriate expression for the
blank A?
F(0) = 1
F(n) = 	A 	(if n > 0)

a) n + F(n - 1)
b) n - 1 + F(n)
c) n × F(n - 1)
d) (n - 1) × F(n)
?
c) n × F(n - 1)
