In machine learning, which of the following best describes the supervised learning?

a) It helps find previously unknown features or patterns on a dataset without pre-existing labels.
b) It tries to find the best action by evaluating each result of possible actions in a specific situation.
c) It is used to get a correct answer for new input data after being trained on a dataset with answer keys.
d) It is used to make a prediction about the actions of a user by collecting and analyzing behavioral data.
?
