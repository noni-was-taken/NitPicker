# 2022S_FE_AM_15
Which of the following is a characteristic of an HA (High Availability) cluster
configuration based on a hot standby method when it is compared to a load distribution
cluster configuration that uses a load balancer?

a) A server that has the same specifications is necessary as the secondary server, but since the secondary server takes over the processes in the event of the failure of the primary server, the throughput can be maintained even in the event of a failure.
b) Given that processes are distributed to other operational servers in the event of a failure, the load on the servers in operation increases, and the throughput decreases.
c) Given that processes can be distributed uniformly, server machines can be utilized effectively, and expandability is ensured, even if the amount of processing increases in the future.
d) Given that processes must be consistent among multiple servers in operation, it is necessary to share a database.
?
a) A server that has the same specifications is necessary as the secondary server, but since the secondary server takes over the processes in the event of the failure of the primary server, the throughput can be maintained even in the event of a failure.
