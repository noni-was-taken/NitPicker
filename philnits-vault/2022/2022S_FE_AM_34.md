# 2022S_FE_AM_34
Which of the following is the broadcast address of the network with the address
192.168.128.0/26? Here, the decimal number after the slash (/) is the number of bits used for
the network prefix.

a) 192.168.128.63
b) 192.168.128.127
c) 192.168.128.252
d) 192.168.128.255
?
a) 192.168.128.63
