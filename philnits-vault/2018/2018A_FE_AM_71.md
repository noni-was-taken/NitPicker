# 2018A_FE_AM_71
Which of the following is an appropriate example of a core technology?

a) It is a development technology by combining general components with the purpose of fast-track development and fast-track market introduction of products.
b) It is a device technology that employs the same CPU core as that of competitors and enhances the portability of software.
c) It is an idling stop technology of an automobile engine that cannot be imitated by competitors.
d) It is an interface technology whose purpose is to create standard interfaces by forming an alliance and to use them commonly.
?
c) It is an idling stop technology of an automobile engine that cannot be imitated by competitors.
