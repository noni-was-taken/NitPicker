# 2019A_FE_AM_41
In ISO/IEC 27000:2018 (Information Security Management Systems – Overview and
Vocabulary), which of the following is defined as the “property that an entity is what it
claims to be”?

a) Accountability
b) Authenticity
c) Nonrepudiation
d) Reliability
?
b) Authenticity
