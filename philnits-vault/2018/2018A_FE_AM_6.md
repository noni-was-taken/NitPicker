# 2018A_FE_AM_6
Data A, B, C and D are entered as an input sequence. Which of the following is a
possible output sequence by only using a single stack?

a) A, D, B, C
b) B, D, A, C
c) C, B, D, A
d) D, C, A, B
?
c) C, B, D, A
