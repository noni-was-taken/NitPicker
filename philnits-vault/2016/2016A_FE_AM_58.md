# 2016A_FE_AM_58
When a version management system for source code is installed, which of the
following is an appropriate check point to be added for the confidentiality of the source code
during the system audit?

a) The access control settings of the version management system are appropriate.
b) The installation cost of the version management system is at a proper level.
c) The results of the change registered in the version management system are approved by the person in charge.
d) The version management system is selected by the development department.
?
a) The access control settings of the version management system are appropriate.
