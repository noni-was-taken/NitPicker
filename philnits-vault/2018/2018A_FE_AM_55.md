# 2018A_FE_AM_55
In order to determine the quality condition in a test process, it is necessary to analyze and
evaluate the relationship between the number of completed test items and the cumulative
number of bugs. Which of the following is the graph that indicates that the quality is
becoming stable?

a) Number of completed test items Cumulative number of bugs
b) Number of completed test items Cumulative number of bugs
c) Number of completed test items Cumulative number of bugs
d) Number of completed test items Cumulative number of bugs
?
d) Number of completed test items Cumulative number of bugs
