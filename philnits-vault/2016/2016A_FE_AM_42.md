contents of a web server?

a) Communications to the web server are monitored to ensure that there is no communication other than HTTP and HTTPS. [2016A_42_opt_a.png]
b) The hash value of each file of the contents of the web server is stored and periodically compared with the hash value generated from each file. [2016A_42_opt_b.png]
c) The memory usage of the web server is checked periodically to ensure that a buffer overflow has not occurred. [2016A_42_opt_c.png]
d) The updated date of each file of the contents of the web server is stored and compared periodically with the updated date of each file. [2016A_42_opt_d.png]
