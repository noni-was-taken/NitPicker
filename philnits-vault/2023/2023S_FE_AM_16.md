# 2023S_FE_AM_16
When system availabilities of a cold standby system, a simplex system, and a dual system
are compared, which of the following shows the order arranged from highest to lowest? Here
a computer or computers that compose each system are all the same.

a) Cold standby system, dual system, simplex system
b) Cold standby system, simplex system, dual system
c) Dual system, cold standby system, simplex system
d) Simplex system, cold standby system, dual system
?
c) Dual system, cold standby system, simplex system
