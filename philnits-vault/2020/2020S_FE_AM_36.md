# 2020S_FE_AM_36
Which of the following is an attack using a trial-and-error method to obtain confidential
information such as a user password or personal identification number (PIN)?

a) Brute force
b) Denial of service
c) Man-in-the-middle
d) Sniffing
?
a) Brute force
