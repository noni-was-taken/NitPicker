# 2016A_FE_AM_8
Which of the following best describes the characteristics of XML?

a) The style languages such as XSL and CSS used in HTML can also be used in XML.
b) XML allows a tag to be defined in order for an easier data exchange between information systems over the network.
c) XML is developed on its own specification, whereas HTML is on the SGML basis.
d) XML is HTML based and has some features added primarily for a performance improvement of displaying a web page.
?
b) XML allows a tag to be defined in order for an easier data exchange between information systems over the network.
