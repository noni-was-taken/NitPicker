# 2020S_FE_AM_16
When the number of concurrently running programs is increased in a virtual storage
system with a small and insufficient main memory capacity, which of the following is the
state in which the overhead of the system increases and the processor utilization of the
applications decreases?

a) Bottleneck
b) Fragmentation
c) Paging
d) Thrashing
?
d) Thrashing
