# 2016S_FE_AM_52
The integration test for a software that is composed of a set of modules arranged in a
hierarchical structure is performed from a low-level module. In such a case, which of the
following is a test module used as a substitute for a higher level module?

a) Driver [2016S_52_opt_a.png]
b) Emulator [2016S_52_opt_b.png]
c) Simulator [2016S_52_opt_c.png]
d) Stub [2016S_52_opt_d.png]
?
a) Driver
