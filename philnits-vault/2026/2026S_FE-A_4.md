# 2026S_FE-A_4
In regular expressions (regex), which of the following is the string that correctly matches
the pattern ^\d{2,4}-\d+-\d{3,4}$ ? Here, “\d” represents a decimal digit 0-9, the “+”
symbol indicates one or more repetitions, and the “$” symbol denotes the line's end.

a) 12312
b) 15678
c) 1237890
d) 12345910
?
c) 1237890
