# 2023S_FE_AM_6
Which of the following is an error detection method where, on the sender side, the data sent
accompanies a remainder of the data bit sequence divided by a specific generator polynomial,
while on the receiver side, error detection is performed by checking if the received bit sequence
is divisible by the same polynomial?

a) CRC
b) Hamming code
c) Horizontal parity check
d) Vertical parity check
?
a) CRC
