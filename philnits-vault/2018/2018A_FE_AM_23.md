# 2018A_FE_AM_23
By using a sensor that detects changes in shape, the condition of infrastructure such as
elevated highways can be monitored and maintained. Which of the following is a sensor
that is used for this purpose?

a) Gyro
b) Hall element
c) Strain gage
d) Thermistor
?
c) Strain gage
