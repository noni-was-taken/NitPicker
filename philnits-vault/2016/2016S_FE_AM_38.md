# 2016S_FE_AM_38
On the Internet, sometimes when one tries to load a Web page by specifying a URL like
http://www.jitec.ipa.go.jp/, the page does not show up and an error page is shown instead.
However, one can browse this page correctly by specifying its IP address like this:
http://118.151.146.137/. Which of the following TCP/IP layer is responsible for this
problem?

a) Application layer [2016S_38_opt_a.png]
b) Internet layer [2016S_38_opt_b.png]
c) Network Interface layer [2016S_38_opt_c.png]
d) Transport layer [2016S_38_opt_d.png]
?
a) Application layer
