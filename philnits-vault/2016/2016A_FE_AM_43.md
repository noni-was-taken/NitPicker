# 2016A_FE_AM_43
When a digital certificate has been installed in an in-house system accessed from a
smartphone by an employee, which of the following can be checked using the in-house
system?

a) Ensuring that the applications on the smartphone are the latest versions of the applications [2016A_43_opt_a.png]
b) Ensuring that the most recent security patch has been applied to the OS of the smartphone [2016A_43_opt_b.png]
c) Ensuring that the smartphone has been allowed to access the in-house system
d) Ensuring that the smartphone is not infected by a virus [2016A_43_opt_d.png]
?
c) Ensuring that the smartphone has been allowed to access the in-house system
