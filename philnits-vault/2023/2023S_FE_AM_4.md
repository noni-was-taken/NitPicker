# 2023S_FE_AM_4
Random(n) is a function that returns an integer of 0 or more and less than n with a uniform
probability. When the series of procedures below is run on the integer type variables A, B, and
C, what is the probability that the value of C will be 0?
A = Random(10)
B = Random(10)
C = A−B

a) 1 100
b) 1 20
c) 1 10
d) 1 5
?
c) 1 10
