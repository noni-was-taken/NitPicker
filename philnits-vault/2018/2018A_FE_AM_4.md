# 2018A_FE_AM_4
Which of the following is the computational complexity of the Heapsort algorithm? Here,
n is the number of elements to be sorted. All comparisons, swaps, and other needed
operations can proceed in constant time.

a) O (log n)
b) O (n)
c) O (n 2)
d) O (n log n)
?
d) O (n log n)
