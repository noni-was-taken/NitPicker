# 2019A_FE_AM_19
Which of the following is an explanation of an absolute path name in a file system?

a) The path name from the current directory to the target file
b) The path name from the home directory to the target file
c) The path name from the root directory to the target file
d) The shortest path name among path names from a certain directory to the target file
?
c) The path name from the root directory to the target file
