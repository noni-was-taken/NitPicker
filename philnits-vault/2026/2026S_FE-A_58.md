# 2026S_FE-A_58
A factory manager is planning the costs for the next two years. Instead of using a single
estimate, the manager runs thousands of simulations where material prices, customer
demand, and labor costs vary randomly within realistic ranges. This creates a probability
distribution of possible costs, helping in risk planning and setting contingency budgets.
Which of the following is an analytical method that the manager is using?

a) Linear Programming
b) Monte Carlo Analysis
c) Scenario Analysis
d) Sensitivity Analysis
?
b) Monte Carlo Analysis
