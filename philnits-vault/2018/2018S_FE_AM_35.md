# 2018S_FE_AM_35
A PC and a web server are communicating via HTTP. When a request packet is sent
from the PC to the web server, which of the following combinations of port numbers does
the response packet have? Here, the source and the destination port numbers of the request
packet are 50001 and 80 respectively.
Source (web server) port number Destination (PC)
port number

a) 80 50001
b) 50001 80
c) A number allocated on the web server, other than 80 and 50001 80
d) A number chosen by the web server other than 80 or 50001 50001
?
a) 80 50001
