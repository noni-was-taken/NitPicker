# 2019A_FE_AM_14
When two computers have been prepared, and the computer in use fails, which of the
following is the system that continues processing by promptly switching to the backup
computer that has started the same online processing programs as those on the currently-
used computer in advance, and is on standby?

a) Cold standby system
b) Hot standby system
c) Multiprocessor system
d) Multiuser system
?
b) Hot standby system
