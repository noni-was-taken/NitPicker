# 2020S_FE_AM_45
SSL/TLS is the industry-standard security technology creating encrypted connections
between a web server and a web browser. This is used to maintain data privacy and to protect
the information in online transactions. The steps for establishing an SSL/TLS connection are
randomly listed as follows:
1. The web server sends a copy of its SSL/TLS certificate to the web browser.
2. SSL/TLS encrypted communication takes place between the web browser and the web
server.
3. The web server sends the web browser an acknowledgment to start an SSL/TLS
encrypted connection.
4. The web browser checks if the SSL/TLS certificate is trustworthy or not. If it is
trustworthy, then the web browser sends a message to the web server requesting to
establish an encrypted connection.
5. A web browser tries to connect to the web server secured with SSL/TLS.
Which of the following is the correct step sequence?

a) 1 → 5 → 2 → 3 → 4
b) 1 → 5 → 4 → 3 → 2
c) 5 → 1 → 2 → 3 → 4
d) 5 → 1 → 4 → 3 → 2
?
d) 5 → 1 → 4 → 3 → 2
