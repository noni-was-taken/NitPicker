# 2023S_FE_AM_48
In the error embedding method, when the number of embedded errors is S, the number of discovered errors from the embedded errors is m, the number of latent errors before the start of testing not including embedded errors is T, and the total number of discovered errors is n, which of the following expresses the relationship of S, T, m, and n?

a) $\dfrac{m}{S} = \dfrac{n-m}{T}$
b) $\dfrac{m}{S} = \dfrac{T}{n-m}$
c) $\dfrac{m}{S} = \dfrac{n}{T}$
d) $\dfrac{m}{S} = \dfrac{T}{n}$
?
a) $\dfrac{m}{S} = \dfrac{n-m}{T}$
