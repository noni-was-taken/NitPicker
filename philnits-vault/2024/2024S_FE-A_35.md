# 2024S_FE-A_35
Which of the following represents the appropriate combination of a class and an object in
Object Oriented Programming?
Class 	Object

a) A class can be defined as a group of objects with similar behavior and attributes. An object is an instance of a class.
b) A class can be defined as a group of objects with similar behavior and attributes. An object is the blueprint of the class.
c) A class is an instance of objects. An object can be defined as a template that describes the behavior that the class of its type supports.
d) A class stores the actual values of its attributes. An object has the definition and behavior of a class.
?
a) A class can be defined as a group of objects with similar behavior and attributes. An object is an instance of a class.
