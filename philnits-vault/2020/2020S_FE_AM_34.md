# 2020S_FE_AM_34
There is a PC whose IP address and subnet mask are shown below. Which of the
following is the network address of this PC?
IP address: 	10.170.70.19
Subnet mask: 	255.255.255.240

a) 10.170.70.0
b) 10.170.70.16
c) 10.170.70.31
d) 10.170.70.255
?
b) 10.170.70.16
