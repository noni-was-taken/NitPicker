# 2020S_FE_AM_17
When the least recently used (LRU) method is used for swapping a block between cache
memory and main memory, which of the following is a block in cache memory to be replaced?

a) A block for which the longest period of time has elapsed since it was added
b) A block for which the longest period of time has elapsed since it was last referenced
c) A block that has been referenced the least frequently
d) A block that has not been referenced for a certain period of time
?
b) A block for which the longest period of time has elapsed since it was last referenced
