# 2018A_FE_AM_34
In TCP/IP, which of the following is an application layer protocol that enables a server to
automatically configure its clients with network information such as IP addresses, the
subnet mask and the default gateway address?

a) ARP
b) DHCP
c) DNS
d) NSLOOKUP
?
b) DHCP
