# 2016A_FE_AM_34
Concerning email protocols, which of the following descriptions is correct?

a) IMAP allows the message to remain on the server even after it is downloaded to a local PC. [2016A_34_opt_a.png]
b) IMAP uses UDP for faster downloading of emails, whereas POP3 uses TCP.
c) POP3 and IMAP uses the same port number for interoperability in email communication. [2016A_34_opt_c.png]
d) POP3 is used for sending email messages from the sender’s mail server to the receiver’s mail server. [2016A_34_opt_d.png]
?
a) IMAP allows the message to remain on the server even after it is downloaded to a local PC.
