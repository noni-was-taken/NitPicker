# 2023S_FE_AM_17
A printer prints 400 characters per second. The printer uses interrupt-driven I/O and each
character printed requires an interrupt that takes 50 microseconds. What percentage of the
printer's CPU is available to do other work during printing? Here, other overhead time for the
CPU can be ignored.

a) 98
b) 96
c) 4
d) 2
?
a) 98
