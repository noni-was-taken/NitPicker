# 2020S_FE_AM_44
Which of the following is the network security tool that is usually deployed by a network
or system administrator and presents itself as a target machine trying to lure attackers to
observe their behavior and attack methodology without harming other systems?

a) Honeypot
b) Logic analyzer
c) Protocol analyzer
d) Rootkit
?
a) Honeypot
